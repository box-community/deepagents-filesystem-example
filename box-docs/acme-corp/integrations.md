# Integrations Guide

## Supported Platforms

### Version Control
- GitHub (Cloud & Enterprise)
- GitLab (Cloud & Self-hosted)
- Bitbucket
- Azure DevOps

### CI/CD
- GitHub Actions
- GitLab CI
- Jenkins
- CircleCI
- Travis CI

### IDE Plugins
- VS Code Extension
- JetBrains Plugin (IntelliJ, WebStorm, PyCharm)
- Neovim LSP

## API Access
All products include REST API access on Team and Enterprise plans.
Rate limits: 1000 requests/hour (Team), Unlimited (Enterprise)
